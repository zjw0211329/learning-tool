# 02 需求规格说明书（SRS）

> 项目代号：study tools —— 大学四年个人学习管理软件
> 版本：v1.0（MVP）
> 日期：2026-09-19
> 前置文档：《01 竞品调研报告》

## 1. 引言

### 1.1 目的
定义 study tools 第一版（MVP）的功能边界与非功能要求，作为设计、开发、测试与验收的依据。

### 1.2 背景与定位
使用者将在大学四年内持续学习多个技术方向（第一个方向：嵌入式）。现有工具（笔记软件、打卡软件、路线图网站）彼此割裂，无法以"学习方向"为主线记录与推进学习过程。本软件定位为**单机个人学习管理工具**：以方向为单位，拆解为阶段与任务，一步步勾选推进，并记录学习日志、生成统计与回顾。

### 1.3 用户与使用场景
- 用户：单用户（开发者本人），无注册登录。
- 场景：在个人电脑上本地运行，浏览器访问；每天学习后花 1~2 分钟记录；周末查看回顾。

## 2. 软件形态（已确认决策）

| 决策项 | 结论 | 依据 |
|---|---|---|
| 形态 | 本地 Web 应用 | 竞品调研 + 用户确认：开发快、跨平台、数据在本机 |
| 部署 | 一条命令启动（`python app/main.py` 或双击 run.bat），浏览器打开 http://127.0.0.1:5000 | 零部署成本 |
| 数据 | 本地 SQLite 单文件（`app/data/study.db`），备份=复制文件 | 本地优先、隐私 |
| 网络 | 完全离线可用（前端库本地化，不依赖 CDN） | 校园网/无网环境可用 |

## 3. 功能需求（MVP 范围，已确认）

### FR1 方向管理（核心）
- FR1.1 创建学习方向（名称 + 一句话描述），如「嵌入式」。
- FR1.2 方向列表总览：每个方向显示任务总数、已完成数、进度百分比、累计学习时长、连续记录天数。
- FR1.3 编辑、删除方向（删除需确认，级联删除其阶段/任务/日志）。

### FR2 路线图与进度（核心）
- FR2.1 三级结构：方向 → 阶段（Phase）→ 任务（Task）。阶段含名称与目标说明；任务含标题与备注。
- FR2.2 任务状态机：未开始（todo）→ 进行中（doing）→ 已完成（done）；另有「跳过（skipped）」。状态变更记录完成时间。
- FR2.3 进度计算：任务/阶段/方向三级进度 = 已完成任务数 ÷ 总任务数（跳过不计入分母）。
- FR2.4 阶段与任务的增删改；任务在同一阶段内的增删改在当前版本不做拖拽排序（记入 V2）。

### FR3 学习日志 TIL（服务于统计与回顾）
- FR3.1 按日期记录学习日志：日期、时长（分钟，可空）、内容（一段话：学了什么、踩了什么坑）。
- FR3.2 日志归属于方向；按时间倒序展示；支持编辑与删除。
- FR3.3 同一天可有多条日志。

### FR4 统计与回顾（核心）
- FR4.1 学习热力图：以日历热力图展示每日学习时长（近一年，GitHub 贡献图风格，依据日志分钟数）。
- FR4.2 周学习时长条形图（近 12 周）。
- FR4.3 汇总指标：累计时长、活跃天数、当前连续记录天数（streak）、阶段进度条。
- FR4.4 周报回顾：选择任一周，展示该周每日日志时间线、完成的任务清单、合计时长。

### FR5 数据管理
- FR5.1 首次运行自动建库建表。
- FR5.2 一键载入「嵌入式」示例数据（内置 API，前端空状态页提供按钮），便于演示与验收。
- FR5.3 数据导出为 JSON（整库备份），V2 再做导入。

## 4. 明确不做（Out of Scope for MVP → 排期到 V2+）

- 复习卡片（Anki/FSRS 间隔重复）
- 番茄钟 / 打卡
- 多用户、云同步、账号体系
- 移动端适配优化（仅保证桌面浏览器可用）
- 任务拖拽排序、跨阶段移动
- AI 生成学习路线图
- 笔记软件对接（Obsidian/思源导出）

## 5. 非功能需求

| 编号 | 要求 |
|---|---|
| NFR1 | 性能：单用户本地使用，页面操作响应 < 200ms；统计查询基于 SQLite 索引 |
| NFR2 | 可维护性：代码分层清晰（路由/数据访问分离），有中文注释；对大一~大四的学生开发者可读 |
| NFR3 | 可移植：仅依赖 Python + Flask；Windows/macOS/Linux 均可运行 |
| NFR4 | 数据安全：所有写操作参数化 SQL，防注入；删除操作前端二次确认 |
| NFR5 | 易用性：界面中文，新建方向到记录第一条日志 ≤ 3 步 |

## 6. 验收标准（抽样）

1. 空库启动 → 显示引导页 → 点击「载入示例数据」→ 出现「嵌入式」方向，含 4 个阶段、≥ 15 个任务、≥ 20 天日志。
2. 勾选任一任务为「已完成」→ 方向进度百分比与阶段进度条即时更新。
3. 添加一条当日日志（时长 45 分钟）→ 热力图当日变色、周条形图更新、streak 正确。
4. 周报页选择本周 → 显示本周每日记录、完成 tasks 清单与总时长。
5. 关闭服务重新启动 → 数据完整保留（SQLite 持久化）。
