# 📚 study tools · 大学四年个人学习管理

以**学习方向**为单位（如「嵌入式」），把方向拆成 **阶段 → 任务**，一步步勾选推进；
每天用 **TIL 速记** 记录学了什么、踩了什么坑；用 **热力图 / 周时长 / 周报回顾** 看见自己的坚持。

> 单机本地 Web 应用：数据全部存在本机 SQLite，无账号、无云端、完全离线可用。

## 快速开始

```bash
# 1. 安装依赖（共两个第三方包：Flask + fsrs）
pip install -r requirements.txt

# 2. 启动（或直接双击 run.bat）
python app/main.py

# 3. 浏览器打开
#    http://127.0.0.1:5000
```

首次使用：首页点 **「载入示例数据（嵌入式）」** 可以一键看到完整效果（含 4 个阶段、17 个任务、
约 60 天学习记录、6 张复习卡），之后删掉示例方向即可开始记录自己的。

## 功能一览

### v1.0（MVP）

| 模块 | 功能 |
|---|---|
| 方向管理 | 创建 / 编辑 / 删除学习方向，总览进度、累计时长、连续天数 |
| 路线图与进度 | 方向 → 阶段 → 任务三级结构；状态：未开始 → 进行中 → 已完成（可跳过）；三级进度条实时联动 |
| 学习日志 TIL | 按日期记录时长与心得，时间线回看，支持编辑删除 |
| 统计与回顾 | 近一年学习热力图、近 12 周时长条形图、阶段进度、周报（每日时间线 + 完成任务清单） |

### v2.0

| 模块 | 功能 |
|---|---|
| 排序与移动 | 阶段 / 任务上移下移；任务跨阶段移动；状态圆点四态循环（未开始→进行中→已完成→跳过） |
| 数据安全 | 一键导出全量 JSON 备份；导入备份整库恢复（单事务，失败自动回滚） |
| 番茄钟 | 25 分钟专注 + 5 分钟休息；专注结束自动把 25 分钟记入当日学习日志；标签页标题实时显示倒计时 |

### v3.0（当前版本）

| 模块 | 功能 |
|---|---|
| 复习卡片（FSRS 间隔重复） | 卡片归属方向、正反面管理；今日队列 = 到期卡 + 每日上限 10 张新卡；翻面后四级评分（忘记/困难/良好/简单），FSRS-6 算法自动排期；复习视图顶部四项计数，方向详情页「今日待复习」徽标 |
| 备份兼容 v2 | 备份格式升为六表（含卡片与复习记录）；v1 旧备份仍可导入；高版本备份明确提示升级 |

## 自动化测试

```bash
# 推荐方式：临时独立数据库 + Flask test_client，零副作用，无需启动服务
python tests/api_smoke.py

# 或对运行中的真实服务做回归（只读 + 自建临时数据，结束自动清理）
STUDY_TOOLS_URL=http://127.0.0.1:5000 python tests/api_smoke.py
```

覆盖：全链路 CRUD、状态机、进度口径（列表 × 详情 × 统计三方互验，含分母边界）、统计/周报、
级联删除、静态资源离线可用、示例数据验收（含 6 张复习卡与动态到期时间）、排序与跨阶段移动、
导出导入与非法备份拒绝（v1/v2 兼容矩阵 + 对抗探针）、日志 limit、导入后 id 序列安全、
FSRS 调度基准与队列语义、自包含迁移测试、非对象 JSON 体拒绝，临时库模式共 262 项断言。

## 技术栈

- **后端**：Python 3 + Flask 3 + SQLite（标准库 sqlite3）+ FSRS-6（官方 Python 包 `fsrs==6.3.2`，间隔重复调度）
- **前端**：Vue 3 + ECharts 5（vendor 本地化，无需 Node 构建）
- **启动**：`pip install -r requirements.txt` 后一条命令 / 双击 run.bat
